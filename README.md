# Data Processing Code for Dual-Modal Wearable Imaging (FUSION)

This repository contains the supplementary data processing scripts for the manuscript: 
**"Wearable fluorescence–ultrasound imaging reveals cross-scale neurovascular dissociation and network reorganization during stroke reperfusion"**

## Overview

This repository provides the customized analytical pipelines used to process the *in vivo* dual-modal neuroimaging data. The code is specifically designed to handle the challenges of long-term continuous recording in freely moving mice, focusing on robust signal extraction from both microscopic (single-photon fluorescence) and macroscopic (ultrasound) modalities.

## Repository Contents

The repository is organized into two main modules:

### 1. Customized CaImAn Pipeline (`/fluorescence_processing`)
A tailored Python pipeline based on the CaImAn (v1.13.0) framework. 
* **Purpose:** Memory-efficient extraction of long-term single-cell calcium traces from miniature single-photon microscopy data.
* **Key Features:** Directly processing continuous long-term recordings within CaImAn requires prohibitive memory overhead. To overcome this, our custom pipeline implements a two-step CNMF-E approach:
  1. **Morphology Initialization:** Extracts precise spatial footprints (cell morphologies) using a representative short-term data segment.
  2. **Long-Term Trace Extraction:** Fixes the extracted spatial components and performs constrained CNMF-E temporal decomposition across the entire long-term dataset. This strategy yields denoised, continuous single-cell traces while drastically reducing memory consumption and ensuring spatial consistency over time.

### 2. WLC-CCA Ultrasound Denoising (`/ultrasound_processing`)
Custom MATLAB scripts implementing the WLC-CCA (Weighted Local Covariance - Canonical Correlation Analysis) algorithm.
* **Purpose:** Specifically designed for advanced clutter filtering and denoising of functional ultrasound data acquired from the wearable probe.
* **Key Features:** Effectively separates slow blood flow signals (critical for analyzing ischemia/reperfusion states) from tissue motion artifacts generated by the unrestrained behavior of the animal.

## System Requirements & Dependencies

The code has been developed and tested in the following environments:

* **Python Environment:**
  * Python 3.10
  * CaImAn 1.13.0
* **MATLAB Environment:**
  * MATLAB 2024b (MathWorks, Inc.)
